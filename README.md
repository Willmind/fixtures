# 我的家 · 房屋说明书

React + TypeScript + Three.js + Vite 实现的户型资料、毛坯实景导览、三维查看器和 CAD 图纸工作台。首页直接展示毛坯三维模型；「户型资料」中按房间关联原图、实拍照片、现场说明和待测事项。各页面、电气原图和视频按需加载。

代码职责、共享资源规则与性能定位方法见 [维护说明](docs/architecture.md)。

## 本地运行

需要 Node.js 22.12+（或符合 Vite 8 要求的更新版本）。

```sh
npm install
npm run dev
```

打开终端显示的本地地址，默认 `http://127.0.0.1:5173`。

```sh
npm run build
npm test
```

## 操作

三维首页免密码，户型资料（含原始图纸、现场实拍与记录）和 CAD 电气图需要输入访问密码。直接打开这些页面的链接也会先显示密码框；输入后进入原来请求的页面。同一标签页内刷新和切换资料页面保留解锁状态，点击锁定清除会话；锁定后仍可浏览三维首页。密码页提供「返回三维首页」入口。

开关保留在 `src/access/passcode.ts` 的 `passwordGateEnabled`，目前为 `true`，`canAccessPage` 管理页面范围。访问框是前端便捷限制，用户提供的户型图衍生资料仍随静态网站发布，详见下方发布范围。

- 首页：打开根网址直接进入毛坯模型，可旋转、缩放、选择房间及切换家具方案。
- 户型资料：从模型页头「户型资料」或 `?view=guide` 进入，查看原图事实、用途候选和需求问题；「图纸说明」解释轴线、尺寸、标高和灯位；「原始图纸」打开 7 页来源图。旧的 `?tab=visit` 等资料链接仍可直接使用，刷新及返回保持所在页面。
- 现场实拍：24 张照片和约 43 秒视频；房间选择与平面图、三维互通。照片可放大，视频可按片段跳转。直接访问 `?tab=visit&room=master` 可打开主卧实拍。资料来源、压缩方式和后续测量计划见 [实景导览说明](docs/site-visit.md)。
- 房间记录：在房间布局或现场实拍中展开「记录与待办」，填写用途、现场尺寸、备注并勾选确认事项。两处读取同一份记录；记录不会自动修改三维模型。
- 浏览定位：在实拍、平面和三维之间切换时保留选中的房间与照片；返回资料恢复阅读位置。手机平面图用编号对应下方房间按钮，点击后定位详情。实拍旁的蓝点仅表示房间位置，不表示拍摄点或朝向。
- 毛坯三维：访问 `?view=model`，或点页头「毛坯三维」。
- 左键拖动 / 单指拖动旋转，滚轮 / 双指缩放，右键 / 双指拖动平移。
- 切换三维和俯视；俯视状态下左键 / 单指拖动平移，仍可缩放。
- 整屋中点击房间文字标签先选中，再点「查看房间」只展示对应空间；电脑侧栏的空间列表、手机的「整屋总览」选择器可直接进入房间。房间视角自动聚焦并隐藏整屋轴线；返回整屋恢复之前的相机位置（切换三维／俯视后使用当前视角预设）。门、家具和灯光状态保留，点击家具仍执行对应交互，地面不负责房间选择。
- 房间介绍默认隐藏，选择空间后点底部「房间介绍」打开卡片；关闭只隐藏文字，保留当前房间视角、选中状态和相机位置，可再次打开。是否显示介绍独立于房间切换；返回整屋使用空间列表的「整屋总览」，不会由关闭介绍触发。
- 模型主操作集中在顶部悬浮卡片：视角、昼夜、空间、方案和显示；「开灯／关灯」与按下式「交互提示」按钮常驻画布，直接操作，无需打开菜单。宽屏按三列两排排列，窄屏与手机按两列三排排列；右侧只保留缩放与恢复视角。桌面「方案／显示」共用一个轻量非模态面板，可点击画布或按 Escape 关闭，面板在工具组下方展开，与右侧工具留出间距；手机设置使用带进出动画、背景遮罩、焦点管理和安全区留白的底部弹层。方案、显示与空间列表不会叠加，选择空间后保留家具状态。
- 三个卧室、书房、两个卫生间与入户门补充门框、门扇和把手；厨房采用沿内侧墙滑开的玻璃推拉门示意，打开后让出完整门洞，两个阳台保持既有敞开连接。门默认打开，点击门扇、把手或门框可平滑开合，支持反向操作与减少动态效果设置；拖动和双指操作不会触发开关。切换视角、墙高及家具方案保留各扇门的状态，半高墙下门随墙截短，门框上沿隐藏。开向、门型和安装尺寸待实测。

- 进入单个房间后默认显示白色交互圆点，配浅灰描边和轻微呼吸效果，不用蓝绿颜色区分状态：柜门、窗户、窗帘、抽屉、灯具、水龙头、炉头、排气扇、机器人和晾衣架共用原有操作目标。桌面悬停或键盘聚焦显示动作；手机直接点击圆点操作，操作后在对应圆点旁短暂显示状态反馈，约 2.2 秒后收起；当前操作的圆点优先展示，连续操作会更新反馈并重新计时。没有可见圆点时使用画布上的简短反馈，屏幕阅读器同步播报。首次进入房间提示一次，点关闭或完成一次操作后记住已读状态。圆点只显示当前房间、可见物体，重叠时隐藏部分提示，缩放后可重新展开；「提示」按钮及显示设置可关闭圆点，关闭不会影响直接点击物品，也不重置家具状态。

### 房间记录与备份

记录存于当前网址的浏览器 `localStorage`（`fixtures-room-notes-v1`），没有上传接口。不同设备、浏览器以及本地预览和线上网址之间不自动同步。清除浏览器数据前应导出 JSON 备份；导入时先预览房间和冲突，默认保留本机已有记录，也可以明确选择用备份替换重复房间。导入前会额外发起一次当前数据备份下载，请确认文件实际保存。

备份限制 200 KB，并验证版本、房间、字段和清单状态。无法读取已有记录时不覆盖原存储；存储被禁用或空间不足时页面保留当前填写并显示导出提示。确认项使用问题内容生成稳定标识，重新排序不会勾错项目，改写或移除的问题不会被旧备份自动确认。相关校验及合并测试位于 `scripts/notebook.test.mjs`。

## 模型来源与精度

参考用户提供的《住宅D户型.pdf》第 1 页墙体开线图、第 2 页平面布置图，图纸日期 2019 年 3 月。四房、两卫、一厨、客餐厅、两阳台；不包含公共电梯和公共管井，装修面层按用户当前偏好示意。客厅家具与生活阳台设备作为可关闭的摆放示意，未选择具体产品。

这是对扫描图的**人工几何重建**，并非 DWG 精确解析。主要开间参考图纸标注，局部门洞、窗洞、墙厚、窗台高度和净尺寸均有简化。部分飘窗、设备平台和细部尚未还原。轴线尺寸并不等于室内净尺寸。墙面外观、深色窗框与玻璃栏板参考实拍，材质分界及构件尺寸仍为示意，不表示承重性质。尚未按现场实测校准，不能作为施工或拆改依据。

默认墙厚 0.20 m、墙高 2.80 m、门洞高 2.20 m 均为示意假设。原客房按用户计划改作书房，内部 ID 仍为 guest 以保留照片和笔记关联；其余卧室分配仍可调整。

原始 PDF、完整 DWG 和身份证件不进入仓库。经用户要求，`public/house/` 发布 D 户型 PDF 的 7 页阅读图片、首页裁图，以及 DWG 的 ZD11 单张电气图（含其引用图块），任何访客都可读取这些静态资产。没有发布合同、身份证件或其他户型的整张工程图。

图片由 PDF 以 2600 像素长边渲染、旋转至正向并裁去扫描边缘，保留图签和说明。来源核对记录见 `docs/house-reading.md`。`src/guide/content.ts` 区分原图事实、用途建议及待核实项。

原始图纸卡片使用 `public/house/thumbnails/` 中长边 720 像素的缩略图，打开弹窗后才请求对应高清原图。更换原图后，用安装了 Pillow 的 Python 运行 `python3 scripts/generate-sheet-thumbnails.py` 并提交生成的缩略图；正常构建不需要 Python 图片依赖。页面模块加载失败时可重新加载页面，图纸卡片与原图弹窗均支持加载提示和失败重试。

实拍与原图放大时先显示已有缩略图，再切换清晰图片；鼠标或键盘指向图纸入口时预热对应原图，浏览相册时仅预热下一张，开启省流量模式时跳过预热。不会一次下载整本相册。

## CAD 图纸工作台

点击页头「电气图」，或访问 `http://127.0.0.1:5173/?view=cad`。

- 默认自动加载站内 `house/d-electrical.dxf` 并定位照明区域。顶部常驻「灯与开关」「插座与用电」「网络与电视」「综合点位」入口与阅读提示，手机也可直接切换；「显示全图」恢复整张图。
- 开发版可直接选择或拖入 DWG / ASCII DXF，最大 32 MiB。DWG 由本机独立 Node 进程转换，首次转换可能需要十几秒。
- 缩放、拖动平移、「显示全图」、中文图层搜索、逐层开关、仅看某层、全部显示 / 隐藏、深浅背景。
- 「下载 DXF」保存转换结果，以后无需再次转换。导出的中文采用 DXF Unicode 转义，避免旧代码页乱码。

默认电气图优先下载 `house/d-electrical.dxf.gz`，在浏览器内无损解压；不支持解压或请求失败时回退到原 DXF。标注使用只包含本图字符的 `fonts/fixtures-home-cad.ttf`，导入其他文件仍用完整字体。更换默认 DXF 或完整字体后，用安装了 fonttools 的 Python 运行 `python3 scripts/generate-cad-assets.py`，一并提交生成的压缩图纸与字体；正常构建不依赖 fonttools。字体保留原 OFL 许可和版权记录。

- 生产站点仍是纯静态网站，只支持在浏览器导入 DXF。DWG 转换接口仅存在于 Vite 开发服务器，服务器无需安装 CAD，也无需新加后端。
- 刷新后自动恢复家里的默认图；临时导入的其他文件不保存到服务器。图纸工作台是二维原图查看器，不会自动把电气图转成三维墙体。

也可以先运行本地转换命令：

```sh
npm run cad:convert -- "/绝对路径/图纸.dwg"
```

输出在已忽略的 `local-reference/cad/current.dxf`、`current.json`。然后点「打开本机已解析的图纸」，或访问 `http://127.0.0.1:5173/?view=cad&local=1`。不要将该目录放入 `public/` 或提交到 Git。

解析使用独立的 LibreDWG WebAssembly 转换工具，浏览器用 `dxf-viewer` / Three.js 渲染。转换进程需要约 1 GiB WASM 初始内存，因此只放在本机运行，不进入网页包。

已用本次提供的 AC1018 DWG 验证：读取 188 个图层、6,777 个模型空间实体及 761 个块记录，整体图框布局与 Autodesk Viewer 截图对照；尚未逐个实体核对。转换器报告 711 个未知 / 专有对象以及读取警告码 68，部分对象可能缺失。中文使用替代字体，线型、填充、标注和专有 CAD 对象可能与 Autodesk 不同。它适合学习、浏览和核对，不作为精确施工依据。

转换工具根据原 DWG 的图层开关修正 DXF 导出器错误的负颜色值。工作台保留原文件的初始隐藏 / 冻结状态，同时准备冻结图层的几何，使其可以手动显示。修改显隐只影响当前视图，下载保持原始状态。

### 相关代码和许可证

- `src/cad/CadWorkspace.tsx`：CAD 界面、文件读取、渲染器生命周期。
- `src/cad/document.ts`：编码识别、校验、冻结图层处理。
- `scripts/convert-dwg.mjs`：独立本地转换工具（GPL-3.0-or-later）。
- `scripts/cad-dev-plugin.ts`：仅开发环境的本机转换接口，限制文件大小、转换并发和执行时间。
- `public/fonts/`：本地中文替代字体与 OFL 许可证；查看图纸时无需请求外部字体服务。

第三方来源和许可证见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。

## 修改模型

- `src/model/plan.ts`：房间多边形、墙线、门窗开口、轴线标注。长度单位为米；x 从图纸左到右，z 从图纸上到下；不代表地理朝向。
- `src/model/geometry.ts`：从墙体中减去门窗开口，支持半高截断。
- `src/model/HomeScene.ts`：Three.js 场景、OrbitControls、选择与资源释放。按需渲染，无交互时停止帧循环。
- `src/HomeViewer.tsx`：毛坯查看器界面与参数。
- `src/App.tsx`：房屋说明书、毛坯三维和 CAD 工作台的入口切换，支持浏览器返回。
- `src/guide/`：通俗讲解、原图导览和来源阅读。
- `src/visit/`：房间实拍、待测事项、照片阅读与视频片段。
- `src/navigation.ts`：平面、实拍、三维和 CAD 的 URL 状态。
- `scripts/extract-home-cad.mjs`：从本地转换结果提取 ZD11，递归保留必要图块。

更新现场测量数据时，先修正 `plan.ts`，再运行几何测试和浏览器检查。

## 自动部署

GitHub Actions 在推送 `main` 后测试、构建并发布静态产物，腾讯云服务器每分钟检查更新，失败保留上一版。服务器首次初始化、状态检查和回退方法见 [部署说明](deploy/README.md)。
