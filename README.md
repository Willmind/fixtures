# 我的家 · 房屋说明书

React + TypeScript + Three.js + Vite 实现的房屋说明书、毛坯户型查看器和 CAD 图纸工作台。首页直接展示 D 户型原图，配合房间导览和通俗说明；三维和电气原图按需加载。

## 本地运行

需要 Node.js 22.12+（或符合 Vite 8 要求的更新版本）。

```sh
npm install
npm run dev
```

打开终端显示的本地地址，默认 `http://127.0.0.1:5173`。

```sh
npm run build
npm test
```

## 操作

当前已启用前端访问密码，首页、三维和 CAD 链接均先显示居中的密码输入页。进入后可用锁定按钮清除当前会话。

开关位于 `src/access/passcode.ts` 的 `passwordGateEnabled`；修改密码摘要会让旧密码保存的会话失效。验证状态使用 `sessionStorage`，不保存明文密码；锁图标可清除会话。它仅为前端访问入口，并非服务器认证，源码和静态资源仍公开。用户提供的户型图衍生资料随网站发布，详见下方发布范围。

- 首页：点击房间查看原图事实、用途候选和需求问题；「图纸怎么看」解释轴线、尺寸、标高和灯位；「查原图」打开 7 页来源图。
- 毛坯三维：访问 `?view=model`，或点页头「毛坯三维」。
- 左键拖动 / 单指拖动旋转，滚轮 / 双指缩放，右键 / 双指拖动平移。
- 切换三维和俯视；俯视状态下左键 / 单指拖动平移，仍可缩放。
- 点击地面或空间列表选中房间。
- 切换半高墙、完整墙高、房间名称、图纸轴线尺寸和参考网格。
- 完整墙高模式可调整示意墙高，默认 2.80 m。
- 右侧按钮支持缩放和恢复当前视角。画布获得焦点后可用方向键平移。

## 模型来源与精度

参考用户提供的《住宅D户型.pdf》第 1 页墙体开线图、第 2 页平面布置图，图纸日期 2019 年 3 月。四房、两卫、一厨、客餐厅、两阳台；不包含公共电梯、公共管井、家具和装修面层。

这是对扫描图的**人工几何重建**，并非 DWG 精确解析。主要开间参考图纸标注，局部门洞、窗洞、墙厚、窗台高度和净尺寸均有简化。部分飘窗、设备平台和细部尚未还原。轴线尺寸并不等于室内净尺寸。墙体统一材质不表示承重性质。尚未按现场实测校准，不能作为施工或拆改依据。

默认墙厚 0.20 m、墙高 2.80 m、门洞高 2.20 m 均为示意假设。房间名称不预先决定父母房或书房位置。

原始 PDF、完整 DWG 和身份证件不进入仓库。经用户要求，`public/house/` 发布 D 户型 PDF 的 7 页阅读图片、首页裁图，以及 DWG 的 ZD11 单张电气图（含其引用图块），任何访客都可读取这些静态资产。没有发布合同、身份证件或其他户型的整张工程图。

图片由 PDF 以 2600 像素长边渲染、旋转至正向并裁去扫描边缘，保留图签和说明。来源核对记录见 `docs/house-reading.md`。`src/guide/content.ts` 区分原图事实、用途建议及待核实项。

## CAD 图纸工作台

点击页头「电气图」，或访问 `http://127.0.0.1:5173/?view=cad`。

- 默认自动加载站内 `house/d-electrical.dxf`。按「灯与开关」「插座与用电」「网络与电视」「综合点位」定位同一张图的四个区域。
- 开发版可直接选择或拖入 DWG / ASCII DXF，最大 32 MiB。DWG 由本机独立 Node 进程转换，首次转换可能需要十几秒。
- 缩放、拖动平移、「显示全图」、中文图层搜索、逐层开关、仅看某层、全部显示 / 隐藏、深浅背景。
- 「下载 DXF」保存转换结果，以后无需再次转换。导出的中文采用 DXF Unicode 转义，避免旧代码页乱码。
- 生产站点仍是纯静态网站，只支持在浏览器导入 DXF。DWG 转换接口仅存在于 Vite 开发服务器，服务器无需安装 CAD，也无需新加后端。
- 刷新后自动恢复家里的默认图；临时导入的其他文件不保存到服务器。图纸工作台是二维原图查看器，不会自动把电气图转成三维墙体。

也可以先运行本地转换命令：

```sh
npm run cad:convert -- "/绝对路径/图纸.dwg"
```

输出在已忽略的 `local-reference/cad/current.dxf`、`current.json`。然后点「打开本机已解析的图纸」，或访问 `http://127.0.0.1:5173/?view=cad&local=1`。不要将该目录放入 `public/` 或提交到 Git。

解析使用独立的 LibreDWG WebAssembly 转换工具，浏览器用 `dxf-viewer` / Three.js 渲染。转换进程需要约 1 GiB WASM 初始内存，因此只放在本机运行，不进入网页包。

已用本次提供的 AC1018 DWG 验证：读取 188 个图层、6,777 个模型空间实体及 761 个块记录，整体图框布局与 Autodesk Viewer 截图对照；尚未逐个实体核对。转换器报告 711 个未知 / 专有对象以及读取警告码 68，部分对象可能缺失。中文使用替代字体，线型、填充、标注和专有 CAD 对象可能与 Autodesk 不同。它适合学习、浏览和核对，不作为精确施工依据。

转换工具根据原 DWG 的图层开关修正 DXF 导出器错误的负颜色值。工作台保留原文件的初始隐藏 / 冻结状态，同时准备冻结图层的几何，使其可以手动显示。修改显隐只影响当前视图，下载保持原始状态。

### 相关代码和许可证

- `src/cad/CadWorkspace.tsx`：CAD 界面、文件读取、渲染器生命周期。
- `src/cad/document.ts`：编码识别、校验、冻结图层处理。
- `scripts/convert-dwg.mjs`：独立本地转换工具（GPL-3.0-or-later）。
- `scripts/cad-dev-plugin.ts`：仅开发环境的本机转换接口，限制文件大小、转换并发和执行时间。
- `public/fonts/`：本地中文替代字体与 OFL 许可证；查看图纸时无需请求外部字体服务。

第三方来源和许可证见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。

## 修改模型

- `src/model/plan.ts`：房间多边形、墙线、门窗开口、轴线标注。长度单位为米；x 从图纸左到右，z 从图纸上到下；不代表地理朝向。
- `src/model/geometry.ts`：从墙体中减去门窗开口，支持半高截断。
- `src/model/HomeScene.ts`：Three.js 场景、OrbitControls、选择与资源释放。按需渲染，无交互时停止帧循环。
- `src/HomeViewer.tsx`：毛坯查看器界面与参数。
- `src/App.tsx`：房屋说明书、毛坯三维和 CAD 工作台的入口切换，支持浏览器返回。
- `src/guide/`：通俗讲解、原图导览和来源阅读。
- `scripts/extract-home-cad.mjs`：从本地转换结果提取 ZD11，递归保留必要图块。

更新现场测量数据时，先修正 `plan.ts`，再运行几何测试和浏览器检查。
